# Cognitive Ecology Assessment

**Cognitive Ecology** is an open-source, trauma-informed self-assessment and insight-mapping tool designed to support neurodivergent individuals in better understanding their internal landscape, environmental fit, and relational needs.

This project is led by [The Compassion Collective](https://thecompassioncollective.earth), a disabled and neurodivergent-led cooperative rooted in mutual aid, transformative education, and peer support.

---

## 🌱 Purpose

The Cognitive Ecology Assessment is designed to:

- Support self-reflection and self-determination
- Offer an alternative to deficit-based diagnostic tools
- Visualize complexity without pathologizing it
- Empower users to map their lived experience across cognitive, sensory, emotional, relational, and environmental layers

---

## 🧠 Core Features (Planned)

- Modular question system with adaptive pathways
- Data visualization (radar charts, heat maps, and node-based mapping)
- Reflective journaling prompts
- Qualitative output summaries and strengths-based insights
- No user accounts or data storage (privacy first)
