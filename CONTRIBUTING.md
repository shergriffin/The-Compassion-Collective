# Contributing to the Cognitive Ecology Assessment

Welcome! We’re so glad you’re here.

The Cognitive Ecology Assessment is a trauma-informed, peer-led, open source project grounded in relational justice, accessibility, and neurodivergent wisdom. Whether you’re a coder, writer, designer, educator, dreamer, or detail-lover—we welcome your participation.

---

## 💡 Ways You Can Contribute

We embrace many forms of contribution:

- 💻 Code (frontend, backend, integrations)
- 🖋️ Writing and editing (content clarity, tone, translations)
- 🎨 Design (UX, accessibility, visual layouts)
- 🧠 Accessibility and sensory considerations
- 🗺️ Conceptual input, feature ideas, or user insights
- 🐛 Bug reports, testing, and QA
- 🙌 Emotional support, encouragement, reflections

All contributions are valid. We are building this with care.

---

## 🧘 Working Pace and Boundaries

We move slowly, intentionally, and asynchronously.  
There is no urgency here.  
Please prioritize your own needs and nervous system first.  
We will never punish silence, delay, or absence.

---

## ✨ How to Contribute

1. **Read our Code of Conduct** to ensure alignment
2. **Open an Issue** to suggest a change, report a bug, or share an idea
3. **Fork the repository** and submit a pull request (PR)
4. Or simply **email us** if GitHub is not accessible to you

We believe all access needs are valid. If contributing via GitHub isn’t a fit, just reach out—we’ll find a way.

---

## 🧭 Community Guidelines

- Ask questions before offering solutions
- Assume competence, honor lived experience
- Credit all insight, not just implementation
- No shaming, no fixing—this is a collaborative space
- Be kind to your past, present, and future self
